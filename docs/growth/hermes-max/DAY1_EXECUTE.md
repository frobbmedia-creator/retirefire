Use these as **starting points**, then rewrite so they answer the actual post:

**Coast**
```
Coast and “I can retire” are different questions. Coast is whether this pile might grow to full FIRE by year X if contributions stop. You still need earned income (or another plan) until the full number. I’d also drop the assumed real return by 1 point and see if the coast bar still feels comfortable.
```

**SWR**
```
4% is a research starting point from long US history, not a promise. Longer early-retirement horizons usually deserve a 3.3–3.7% test as well. Spending changes the date faster than bumping the return assumption.
```

**Sequence**
```
Average return is the wrong comfort object. If bad years land in the first decade of withdrawals, the same average can still fail. Cheap test: rerun at −1% real and at 3.5% SWR. If both still work, you’re less fragile than a single 4%/7% spreadsheet.
```

**Barista**
```
Subtract work income from spend, then divide the gap by SWR. Then add healthcare as spend. A premium cliff can erase a lot of paper “barista” savings. Haircut the work income 25% in a second scenario so the job is allowed to get worse.
```

Title: Coast FIRE is a stop-saving number, not a quit-your-job number

```
I keep seeing “I hit my Coast number so I retired.” That’s a different question.

Coast (real terms) is roughly:

coast ≈ full FIRE / (1 + r)^n

Example: $80k spend, 4% SWR → $2M. 27 years to 65, 5% real → ~$534k. The model says additional retirement contributions might drop if you hold that and the life gates pass (healthcare, emergency fund, partner agreement). It does not say you can stop earning today.

I also don’t trust a single coast number, so I run a basic 1,000-path sequence stress test (educational p10/p50/p90 — not a forecast) on top of the deterministic calc.
```
