## Single remaining blocker (credential / account access only)

Stripe products, price IDs, secret keys, and the webhook signing secret live inside the Stripe + Vercel accounts. No agent tool can create them or write the secrets. Once the six environment variables below exist in Vercel (Production + Preview) and a webhook endpoint is registered, checkout goes live with zero further code changes.

Required Vercel env vars:

```
STRIPE_SECRET_KEY
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
STRIPE_WEBHOOK_SECRET
STRIPE_PRICE_ID_MONTHLY
STRIPE_PRICE_ID_ANNUAL
STRIPE_PRICE_ID_REPORT
```

Webhook endpoint to register in Stripe:
`https://retirefire.net/api/stripe/webhook`
Events: `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted`
