## Stripe production integration completed — 2026-08-11

The three live Stripe prices are configured in Vercel Production, the server secret was repaired, and the signed production webhook is enabled. RetireFire uses server-created Checkout Sessions and does not expose or require a Stripe publishable key.

Required Vercel env vars:

```
STRIPE_SECRET_KEY
STRIPE_WEBHOOK_SECRET
STRIPE_PRICE_ID_MONTHLY
STRIPE_PRICE_ID_ANNUAL
STRIPE_PRICE_ID_REPORT
```

Webhook endpoint to register in Stripe:
`https://retirefire.net/api/stripe/webhook`
Events: `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted`

Production verification on 2026-08-11:

- `/pro` returned HTTP 200.
- Monthly, annual, and one-time report Checkout Sessions each returned a Stripe-hosted Checkout URL.
- An unsigned webhook request returned HTTP 400, confirming signature enforcement.
