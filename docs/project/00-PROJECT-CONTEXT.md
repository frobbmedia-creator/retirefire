# RetireFire Pro — Project Context

RetireFire provides transparent retirement-planning education and calculators. The commercial model is additive: **core calculators stay free forever**. Pro purchases fund more advanced workflows, deeper analysis, and reports without putting essential FIRE math behind an account wall.

## Offer

- Pro Monthly: $9/month
- Pro Annual: $79/year
- One-time Pro Report: $19

Stripe Checkout hosts payment collection. The app creates sessions server-side and receives signed lifecycle events through a webhook. User accounts and entitlement persistence are intentionally outside this initial checkout milestone.
